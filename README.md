# Ros2-Technical-Audit
Ce projet met en œuvre un audit de sécurité complet, une analyse de vulnérabilités et un test d'intrusion sur un système robotique distribué conteneurisé sous ROS2 (Robot Operating System). L'objectif principal est d'évaluer la surface d'attaque d'un réseau robotique critique et d'implémenter des mécanismes de sécurisation robustes (Hardening).
